## Executive summary
Acerola AI is an early-stage personal AI assistant designed to bring conversational AI, persistent user memory, multimodal input and focused workspaces into one browser-based experience. Its current architecture combines a responsive web client, an authenticated Supabase backend, an Agent Core orchestration layer and server-side AI provider routing.

Acerola is seeking a suitable sponsor or strategic supporter to help validate, improve and responsibly grow the product. Useful support may include development infrastructure and API credits, technical mentorship, independent product testing, accessibility and security reviews, and carefully scoped financial sponsorship.

## The opportunity
People increasingly use separate tools for conversation, research, writing, coding and document analysis. Acerola's product direction is to make those workflows easier to access through one personal workspace, while keeping account access, memory and external actions under user control. This is a product hypothesis to validate with real users—not a claim that Acerola has achieved product-market fit.

## What exists today
The public repository documents these implemented or integrated elements:
- Responsive browser-based application and mobile navigation.
- Supabase authentication and an authenticated server-side AI gateway.
- OpenAI-first model routing with Gemini failover.
- Agent Core orchestration, tool routing and task/workspace structure.
- Authenticated persistent memory with a local fallback.
- Multimodal request attachments, with a client limit of five files and an individual file-size limit of 8 MB.
- Image generation and spoken-audio generation through backend functions.
- Research, Create, Code, Analyze, Tasks and Memory workspaces.
- GitHub Pages deployment checks and a Python/pytest contract test suite.

Implementation in source code does not, by itself, prove that every feature is reliable in every production environment. Live end-to-end verification is part of the next milestone.

## What Acerola is not claiming
Acerola does not currently claim:
- A verified number of active users, paying customers or retention rate.
- Verified revenue, profitability or recurring subscription growth.
- Independent security certification, a completed penetration test or regulatory compliance.
- Product-market fit or proven competitive superiority.
- Video generation as an available feature.
- That all payment, subscription, provider-fallback and background-job paths have passed live end-to-end acceptance testing.

Future figures should be dated and supported by analytics, payment records, test reports or other evidence.

## Sponsorship priorities
1. **Reliability:** Repeatable end-to-end tests for sign-in, chat, provider fallback, memory, attachments, image/audio generation and failure recovery.
2. **Security and privacy:** Independent review, access-control checks, abuse protection, data-retention decisions and incident procedures.
3. **Product validation:** Structured testing with a small, consent-based group of users and documented feedback.
4. **Infrastructure:** Predictable, capped API and hosting budgets with alerts and usage monitoring.
5. **Accessibility and performance:** Mobile usability, low-bandwidth behaviour, loading performance and clear error states.
6. **Business readiness:** Transparent pricing, payment lifecycle testing, support processes and documented ownership/governance.

## Governance and safeguarding
Acerola is an early-stage project. Any financial, contractual, payment-account, equity or ownership arrangement must be reviewed and handled with an appropriate parent/guardian or responsible adult representative. Never share passwords, API keys, service-role credentials or private user data as part of a sponsorship discussion.

A sponsor should receive project-level progress reports and agreed deliverables—not access to private user conversations or production secrets.
