The product

One workspace. Multiple ways to think and create.

Acerola brings several AI-assisted workflows into a single browser-based experience. The current build combines a responsive client, authenticated backend services and an orchestration layer.

01 · Converse

AI conversation

A conversational interface connected to a server-side AI gateway, with OpenAI-first routing and Gemini failover documented in the repository.

02 · Remember

Persistent memory

Authenticated, user-scoped memory is designed to retain useful context across conversations.

03 · Understand

Multimodal input

Requests can include up to five attachments, with an individual file-size limit of 8 MB in the current client.

04 · Work

Focused workspaces

Research, Create, Code, Analyze, Tasks and Memory organize different kinds of AI-assisted work.

05 · Create

Media generation

Image and spoken-audio generation are integrated through backend functions. Availability should be verified in a live demonstration.

06 · Protect

Account-aware architecture

Supabase authentication and server-side provider credentials help keep privileged keys out of the browser.

What comes next

Build trust before scale.

Near-term priorities

  • Repeatable end-to-end reliability tests.
  • Independent security and privacy review.
  • Mobile, low-bandwidth and accessibility improvements.
  • Consent-based pilot testing and real usage measurement.
  • Verified payment lifecycle and operating-cost reporting.
  • Server-enforced monthly AI usage entitlements.
  • Immediate background-job dispatch with scheduled recovery.

How progress will be measured

  • Successful task completion and error rates.
  • Response time and cost per successful request.
  • Returning-user behaviour in a defined pilot cohort.
  • Documented security findings and remediation.
  • Reconciled payment records, not estimates presented as revenue.
