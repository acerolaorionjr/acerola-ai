## 3. Calculate the request

- Monthly baseline = sum of actual recurring monthly cash costs.
- Pilot costs = one-time quotes + capped incremental usage.
- Contingency = an explicitly approved percentage of the pilot subtotal.
- Requested support = monthly baseline for the agreed period + pilot costs + approved contingency.
- State whether support is cash, credits, services or a mixture.
- Set a hard usage cap, alert threshold, named adult account holder and reporting cadence.

## 4. Evidence to retain

- Dated API usage exports for each provider.
- Supabase and hosting invoices or plan screenshots, with account IDs and personal details redacted.
- Written security-review and testing quotes.
- A short calculation sheet showing quantities, unit prices, period and currency.
- A record of sponsor-approved caps and actual spend.

## 5. Do not include

- Guessed user counts, future revenue or growth projections presented as facts.
- Test transactions as sales.
- Free credits as money received.
- Personal bank details, passwords, API keys or private user data.
- An uncapped promise to cover all future AI usage.

**Safeguarding:** A parent/guardian or responsible adult must be involved in any financial, payment-account or contractual arrangement.
